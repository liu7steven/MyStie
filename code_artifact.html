觀察尿液顏色 - 水分檢測指南

觀察排尿時的顏色是評估身體是否缺水最直覺且準確的方式。點選您目前的尿液顏色以對照水分補充建議：

1
無色透明 / 極淺黃 水分過多

體內水分非常充足，可適度放慢喝水頻率。

2
淡黃色 (檸檬黃/淺麥稈色) 最佳理想

水分平衡極佳，身體運作非常良好！

3
深黃色 / 金黃色 輕微缺水

身體發出微弱缺水訊號，建議儘快喝一杯水。

4
琥珀色 / 烏龍茶色 嚴重缺水

嚴重缺水，請立即大口補充水分並適度休息。

5
深褐濃茶色 / 帶紅色 極度警告

極度缺水或可能與飲食/藥物/健康有關，請特別留意。
